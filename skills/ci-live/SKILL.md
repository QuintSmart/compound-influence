# ci-live

Live-negotiation door for a heated moment.

## Do first

1. Read `references/context-contract.md`.
2. Read `references/authority-engagement-card.md` and `references/negotiation-basics-card.md` (plus short Wang overview if needed).
3. Soft Akte: use existing / create / ohne Akte.

## Default

1. Capture situation + Gegenstimme in one short restatement.
2. Offer 2–3 reply options grounded in the cards (label / listen / smaller ask / silence vs pushback). No feature dump.
3. Write-back default: append chosen or noted option to **Live Log** when an Akte is active.
4. If the operator says **ablehnen** / `skip` / `kein Write-back`, leave the Akte **unchanged** (AE3).

## Do not

- Do not force a single "best" line as the only output.
- Do not overwrite Open Ask without confirm.
- Do not write to the Akte after explicit ablehnen.

## Output

2–3 options in chat; Write-back only when not declined.
