# ci-diagnose

Pre-pitch door. Arena default: QuintSmart Mandanten (Angebot, Pricing, Stakeholder-Buy-in).

## Do first

1. Read `references/context-contract.md`.
2. Read `references/wang-influence-cards.md` (overview) plus `references/pain-cost-gain-card.md` and `references/buyer-map-card.md` for depth.
3. Optionally skim `references/quintsmart-examples.md`.
4. Soft Akte: offer use existing / create / weiter ohne Akte. Do not block if ohne Akte.

## Default

1. Clarify who the real Buyer is (decision + influencers + carriers). For a full walk use `ci-buyer`.
2. Surface Felt Problem with Pain / Cost / Gain. Flag vitamin vs painkiller and structural rejection vs sweetening. For a beat-by-beat walk use `ci-pcg`; if invisible, `ci-mirror`.
3. Name the Open Ask (the next yes that matters).
4. Write-back default: append a dated entry to **Diagnose Log** on the active Akte (Buyer, Felt Problem, Open Ask). Operator may say `skip` / `ohne Akte` / `ablehnen` / `kein Write-back`.
5. Chat-only with an active Akte and no explicit skip is a fail when write-back was expected.

## Do not

- Do not lead with your solution journey.
- Do not treat title/authority as commitment.
- Do not erase prior Diagnose Log entries.

## Output

Short diagnose in chat, then Write-back unless skipped. Point to `ci-frame` or `ci-live` if useful.
