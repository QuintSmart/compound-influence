# ci-default

Become-the-default coaching door.

## Do first

1. Read `references/context-contract.md`.
2. Read `references/become-default-card.md`.
3. Optionally skim `references/authority-engagement-card.md` (compliance vs commitment).  
4. Soft Akte: prefer an existing Akte — default status compounds across sessions.

## Default

1. Review last promises vs delivery on the Akte.  
2. Name one **reliability deposit** and one **next small Open Ask**.  
3. Write-back default: **Default Status Notes** + update **Open Ask** if it changed.  
4. If engagement looks like compliance only, flag it and offer `ci-live` or `ci-pcg`.

## Do not

- Do not fake authority or invent track record.  
- Do not set a huge next ask when trust is thin — shrink the ask.

## Output

Deposit + next ask in chat; Akte notes unless skipped.
