# ci-pcg

Deep Pain/Cost/Gain coaching door. German prompts OK.

## Do first

1. Read `references/context-contract.md`.
2. Read `references/pain-cost-gain-card.md`.
3. Soft Akte: use / create / ohne Akte.

## Default: one beat per turn

1. Name the current beat: Pain | Cost | Gain | Vitamin/Painkiller | Structural check | Mirror handoff.  
2. Ask the card questions for that beat only. Offer a short draft from what is known.  
3. Wait for confirm.  
4. Write-back default: update **Felt Problem (Pain / Cost / Gain)** and append **Diagnose Log** when an Akte is active (skip phrases apply).  
5. Stop. Name the next beat.

If Felt Problem is invisible, hand off to `ci-mirror` rather than pushing evidence.

If wrong buyer / no felt problem: name **structural rejection** — do not invent sweetening.

## Do not

- Do not dump all three axes in one turn unless the operator says fill the rest.  
- Do not pitch features during PCG.  
- Do not erase prior Diagnose Log entries.

## Output

Beats on the card + Akte updates unless skipped. Offer `ci-hic` / `ci-frame` when PCG is solid.
