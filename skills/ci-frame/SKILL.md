# ci-frame

Message-framing door. Destination before route.

## Do first

1. Read `references/context-contract.md`.
2. Read `references/wang-influence-cards.md` (Headline–Insights–CTA, Make your move).
3. Soft Akte: use existing / create / **ohne Akte** (AE2 — framing may run with no vault write).

## Default

1. Take the operator's draft (mail, Angebot, talking points).
2. Rewrite as Headline–Insights–CTA in the Buyer's language. Drop feature-order storytelling.
3. Write-back default: append to **Framing Log** when an Akte is active.
4. Skip phrases (`skip`, `ohne Akte`, `ablehnen`, `kein Write-back`) → chat only, **no vault write**.

## Do not

- Do not require an Akte to produce the rewrite (ohne-Akte path is valid).
- Do not invent Buyer facts missing from Akte or request — mark assumptions.

## Output

Rewritten message in chat; Write-back unless skipped / ohne Akte.
