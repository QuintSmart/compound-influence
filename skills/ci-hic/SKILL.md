# ci-hic

Headline–Insights–CTA coaching door.

## Do first

1. Read `references/context-contract.md`.
2. Read `references/headline-insights-cta-card.md`.
3. Soft Akte: use / create / **ohne Akte**.

## Default: one beat per turn

1. **CTA first (thinking):** What must they do when this ends? Verb by role (approve / own / adopt / reflect) + by when.  
2. Then **Headline** (corridor sentence).  
3. Then at most **three Insights**.  
4. Confirm each beat. Write-back default to **Framing Log** when Akte active; skip / ohne Akte → chat only.  
5. If problem still invisible, send to `ci-pcg` / `ci-mirror` before locking H–I–CTA.

## Do not

- Do not replay the operator's analysis journey as the message order.  
- Do not exceed three insights.  
- Do not require an Akte (ohne-Akte path is valid).

## Output

Locked H–I–CTA in chat; Write-back unless skipped. For a one-shot rewrite of an existing draft, `ci-frame` is enough — use this skill for the drill.
