# ci-buyer

Buyer-map coaching door.

## Do first

1. Read `references/context-contract.md`.
2. Read `references/buyer-map-card.md`.
3. Soft Akte: use / create / ohne Akte.

## Default: one beat per turn

1. Pick one slice: Decision-maker | Influencer | Carrier | Wants | Fears | Constraints | Open Ask.  
2. Ask / draft from the card. Confirm.  
3. Write-back default: update **Buyer Map**, **Wants / Fears / Constraints**, and/or **Open Ask**; append a short **Diagnose Log** note when useful.  
4. Stop. Name the next slice.

If several people compete for „the buyer“, do not silently pick — ask.

## Do not

- Do not invent stakeholders. Mark unknowns.  
- Do not jump to solution or framing until Open Ask is named (or operator overrides).

## Output

Updated map in chat + Akte unless skipped. Offer `ci-pcg` next when buyer is clear but Felt Problem is not.
