# Become the default (deep card)

Operator card for post-yes compounding. Skills: `ci-default`.

## Economics of trust

The first yes is expensive. Later yeses get cheaper through familiarity, commitment/consistency, and lived reliability.

Formula: **Promise → set expectation → deliver → repeat**.

- Reputation = what people hear about you  
- Credibility = what they experience when they meet you  

Reliability compounds; inconsistency discounts.

## Curiosity opens the door

Invite exploration without forcing the big ask. Small solvable knowledge gaps beat big pitches. Give a cost-free way to experience value when possible (trial, sample, short pilot).

## Operator moves

1. Name the last promise and whether it was delivered.  
2. Propose one **reliability deposit** (prepare, deliver, follow through).  
3. Name the **next small Open Ask** that compounds default status.  
4. Write **Default Status Notes** on the Akte (and Open Ask if it changed).

## Link to Cialdini (optional mental model)

Commitment/Consistency and familiarity support default status — still earn through delivery, do not fake authority.
